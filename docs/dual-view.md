# Synchronized full-estate comparison

Open `dual.html`, or select **Dual view** in the existing demo. The latter transfers the current complete estate. **Single view** returns with that estate intact.

Choose a defense, then **Run both**. The two copies of the existing renderer receive identical estate objects, including findings, credentials and deployment assumptions. Pre-LLM uses the LockBit-style profile; ARTEX uses three workers. One animation callback advances both with the same modeled seconds per playback second. Each renderer stops at its own final event, preserving its result while the other continues. Playback duration (30, 60 or 120 seconds) applies to the longer complete run, including response events. These remain illustrative scenario times.

The seed field and **New Infra** generate a full mixed estate on both sides. Reusing a seed regenerates that estate; **Run both** replays the current inputs. Defense changes prepare both views for the next shared start. Full screen fits both complete graphs to the available screen.

Scope: phases 4–6 (timed animation, same-estate comparison and replay). The user reopened UI work for the dual/single selector and shared controls. The single view retains its prior playback behavior; the dual page uses an embedded bridge to its renderer.

Validation: browser checks at 3840 × 2160 verified matching 54-asset estates, one/three attacker markers, equal clock advancement, defense resets, seed regeneration, return to single view with the same estate, and absence of browser errors.
