# Synchronized full-estate comparison

Open `dual.html`, or select **Dual view** in the existing demo. The latter transfers the current complete estate. **Single view** returns with that estate intact.

Choose a defense, then **Run both**. The two copies of the existing renderer receive identical estate objects, including findings, credentials and deployment assumptions. Pre-LLM uses the named gang profile shown above its panel, with one human operator; ARTEX uses three workers. One animation callback advances both with the same modeled seconds per playback second. Each renderer stops at its own final event, preserving its result while the other continues. Playback duration (30, 60 or 120 seconds) applies to the longer complete run, including response events. These remain illustrative scenario times.

**New Infra** draws a fresh seed, updates the displayed seed and generates a full mixed estate on both sides. It also rotates the Pre-LLM gang through LockBit, Conti, BlackCat, Hive and REvil, applying that gang's technique policy. Edit the seed and press Enter or leave the field to reproduce an estate. **Run both** and defense changes retain the current estate and gang. Full screen fits both graphs as discovery progresses. The human operator icon is shared by gang profiles; their name, technique policy and resulting actions distinguish them.

Each panel has a white, independently scrollable activity column on the left with black TTP/CVE entries, newest first. Entries show the actual action, target, modeled time and outcome, preferring the CVE identifier when present. Only completed observed actions appear; unavailable methods and future events are excluded. Replay, defense changes and new infrastructure reset the feeds. The estate uses the remaining panel width through responsive layout and uniform scaling, without a centered right-hand gutter or distorted icons. Single-view layout remains unchanged.

The feed also distinguishes **DATA FOUND**, **DATA EXFILTRATED**, **EXFILTRATION BLOCKED** and **EXFILTRATION STOPPED**. Transfers show the method, destination, records and bytes; malicious ARTEX exports the full accessible dataset through HTTP/API extraction. See [data discovery and exfiltration](data-discovery-and-exfiltration.md) for method sources, prerequisites and timing.

Timed failed checks appear as **NO ACCESS**, while reasoning about a continuation without the required source capability appears as **PATH REVIEW**, naming only the known source. Both show time spent; zero-time exclusions and redundant visits remain omitted. See the [five paired log reviews](activity-flow-audit.md) for progression findings and complete examples.

Scope: phases 4–6 (timed animation, same-estate comparison and replay). The user reopened UI work for the dual/single selector and shared controls. The single view retains its prior playback behavior; the dual page uses an embedded bridge to its renderer.

Validation: browser checks at 3840 × 2160 verified matching 54-asset estates, one/three attacker markers, equal clock advancement, defense resets, seed regeneration, return to single view with the same estate, and absence of browser errors.
